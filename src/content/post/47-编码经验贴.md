 #### 一、快速找到全局安装的 npm 包地址

```bash
npm root -g
# cd 到输出的目录，然后进入
open .
```

#### 二、找到指定端口的 PID ，然后 kill

```bash
ss -tulpn | grep xxxx
kill PID
```
